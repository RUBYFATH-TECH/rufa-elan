## ✨ Visual Effects

### Shadows
- Cards: `shadow-lg` (0 10px 15px -3px)
- Logo Box: `shadow-lg`
- Grand Total: `shadow-lg`

### Opacity
- Decorative circles: `opacity-10`
- Badge background: `bg-opacity-20`
- Badge border: `border-opacity-30`

### Borders
- Cards: `border` (1px solid)
- Left accents: `border-l-4` (4px left border)
- Dividers: `border` or `border-b` (1px)

### Gradients
- Header: `from-teal-600 to-teal-700`
- Customer Card: `from-teal-50 to-cyan-50`
- Payment Card: `from-amber-50 to-orange-50`
- Table Header: `from-teal-500 to-teal-600`
- Grand Total: `from-teal-600 to-teal-700`
- Notes: `from-teal-50 to-cyan-50`
- Footer: `from-gray-800 to-gray-900`

### Hover Effects
- Table Rows: `hover:bg-teal-50`
- Buttons: `hover:shadow-lg`
- Transitions: `transition-all duration-200`

### Border Radius
- Large sections: `rounded-2xl`
- Cards: `rounded-lg`
- Badge: `rounded-lg`
- Circular: `rounded-full`

## 🎯 Visual Hierarchy Priority

1. **Grand Total** - Largest, brightest gradient, catches attention immediately
2. **Order Header** - Large store name, professional branding
3. **Items Table** - Main content, clear layout
4. **Customer Info** - Important for fulfillment
5. **Additional Details** - Date, status, payment info
6. **Footer** - Support contact information

═══════════════════════════════════════════════════════════════════════════════

📞 TROUBLESHOOTING:

Issue: "Using localhost" in mobile-debug
→ Environment variables not set or deployment didn't include them
→ Solution: Redeploy after adding variables

Issue: CORS error
→ Backend doesn't allow your Vercel domain
→ Solution: Add FRONTEND_URL to Render backend

Issue: 503 error
→ Backend is sleeping (Render free tier)
→ Solution: Wait 30-60 seconds, backend will wake up

## 💡 Customization Guide

### Easy Customizations

**1. Change Logo Size**
```tsx
// In any location using Image
<Image 
  src="/logo.png" 
  alt="RUFA ELAN Logo" 
  width={50}  // Change this
  height={50} // And this
  className="object-contain"
/>
```

**2. Change Animation Speed**
```ts
// In tailwind.config.ts
animation: {
  blob: "blob 5s infinite", // Faster
  // or
  blob: "blob 10s infinite", // Slower
}
```

**3. Change Blob Colors**
```tsx
// In app/admin/dashboard/page.tsx
<div className="bg-blue-200" /> // Change to any color
<div className="bg-purple-200" /> // Change to any color
<div className="bg-pink-200" /> // Change to any color
```

**4. Replace Logo Image**
Simply put new image at `/public/logo.png` and it will auto-update everywhere!

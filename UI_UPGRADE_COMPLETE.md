## 💡 Customization Options

### Easy Changes You Can Make

**1. Blob Animation Speed**
- Edit: `tailwind.config.ts`
- Change: `blob 7s infinite` → `blob 5s infinite`

**2. Blob Colors**
- Edit: `app/admin/dashboard/page.tsx`
- Change: `bg-blue-200` → any color

**3. Card Transparency**
- Edit: Any component file
- Change: `bg-white/80` → `bg-white/90`

**4. Gradient Direction**
- Edit: Any component file
- Change: `bg-gradient-to-r` → `bg-gradient-to-b`

**5. Color Scheme**
- Edit: Inline Tailwind classes
- Change: Use different color scales

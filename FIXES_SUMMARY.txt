╔══════════════════════════════════════════════════════════════════════════════╗
║                              THE CRITICAL BUG                                ║
╚══════════════════════════════════════════════════════════════════════════════╝

BROKEN CODE (payments.ts & orders.ts):
    const product = (variant.products as any)?.id ? variant.products : 
                    (variant as any).products;  // ← WRONG! Doesn't exist

WHY IT FAILED:
    1. variant.products exists from Supabase query ✓
    2. Fallback tries to access (variant as any).products ✗
    3. product becomes undefined
    4. productSnapshot has null values
    5. order_items INSERT fails with HTTP 500

FIXED CODE:
    const product = (variant as any).products;
    if (!product) {
      throw new Error(`Product data missing for variant ${productVariantId}`);
    }

RESULT:
    ✅ Direct access to nested relationship
    ✅ Validates product exists
    ✅ Creates valid productSnapshot
    ✅ order_items INSERT succeeds

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Issue: Build fails on Render
Solution: Check logs, verify environment variables

Issue: Build fails on Vercel  
Solution: Check build logs, verify NEXT_PUBLIC_* variables

Issue: CORS errors
Solution: Update CORS_ORIGIN in Render to match Vercel URL exactly

Issue: API calls fail
Solution: Verify NEXT_PUBLIC_BACKEND_URL in Vercel

For detailed troubleshooting, see DEPLOYMENT_GUIDE.md

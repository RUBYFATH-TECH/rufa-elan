## 📋 Quick Implementation Guide

### Step 1: Install (1 minute)
```bash
cd frontend
npm install react-to-print
```

### Step 2: Import (1 minute)
```tsx
import InvoiceReceipt from '@/components/invoice-receipt';
```

### Step 3: Use (1 minute)
```tsx
<InvoiceReceipt
  orderNumber="ORD-2024-001856"
  date={new Date()}
  items={items}
  customer={customer}
  subtotal={42500}
  tax={6375}
  shipping={1500}
  total={50375}
  paymentMethod="Paystack"
  transactionId="PSK-TXN-123456"
  status="completed"
/>
```

## 🔧 Customization Guide

### Change Brand Colors
```tsx
// In invoice-receipt.tsx:
from-teal-600    →  from-blue-600 (your color)
to-teal-700      →  to-blue-700
```

### Update Store Information
```tsx
// Find and update:
<p>📍 YOUR ADDRESS</p>
<p>📧 YOUR EMAIL</p>
<p>📱 YOUR PHONE</p>
```

### Change Currency Symbol
```tsx
// Replace ₦ with your currency
₦50,375.00  →  $50,375.00
```

### Add Your Logo
```tsx
// Replace RF ELAN box with:
<img src="/your-logo.png" className="w-16 h-16" />
```
